# SG-03 – Rajzolás és ismétlésgeometria veszteség nélkül

**Állapot:** megtervezve; ez a kérés nem termékimplementációra szól.

Szabadkézi→Bézier, simítás/sarok/végpont, szerkesztés, Boolean/lyuk/szimmetria; minden ismétléslabor-primitív, kiosztás, taper/metaball/slicing és egyedi eltérés. Közvetlen motívumként használat.
